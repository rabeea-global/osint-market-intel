تنبيهات الحركة اللوجستية والعسكرية (OSINT)

▸ كيف يُحتسب القرار؟
القرار الاتجاهي (شراء/بيع) مصدره الزخم الفني فقط: MACD مقابل خط الإشارة + موضع RSI، مُوحَّد إلى «قوة إشارة» من 0 إلى 100. بوابة الحماية: لا يصدر «شراء» إذا كان RSI ≥ 65 (تشبّع شرائي)، ولا «بيع» إذا كان RSI ≤ 35 (تشبّع بيعي) — في هذه الحالات يتحول القرار إلى «انتظار» مع بيان السبب. إشارات OSINT (اضطراب العرض عند نقاط الاختناق) تعدّل «قوة الإشارة» فقط ولا تغيّر الاتجاه — لأن العلاقة بين الحركة المادية والسعر علاقة وصفية ضعيفة، لا قاعدة تنبؤ. هذه أداة دعم قرار، لا توصية مؤكدة.

Directional call = technicals only (MACD vs signal + RSI), as a 0–100 signal strength. No BUY when RSI ≥ 65, no SELL when RSI ≤ 35 → becomes HOLD with a stated reason. OSINT supply pressure modulates strength only, never direction. Decision-support, not a guaranteed signal.
